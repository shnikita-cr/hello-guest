# Hello Guest

Hello Guest — приложение для ресепшена на входе: заменяет печатную выгрузку Timepad. Импортируете список гостей, ищете человека по имени или номеру билета и отмечаете приход одним касанием. Работает без интернета: локальный сервер на ноутбуке, отметки со всех телефонов синхронизируются в реальном времени.

Данные лежат в файле-журнале `hello-guest.ndjson` в каталоге данных. Исходный файл выгрузки не сохраняется — после импорта данные живут только в журнале. PIN выводится в консоль один раз, при первом запуске: в `config.json` остаётся только его хеш, поэтому запишите PIN сразу, повторно он не показывается.

## Сборка

Два способа, оба создают один файл `dist/hello-guest`:

```sh
make build         # локально на машине, нужен установленный Go
make build-docker  # через Docker-контейнер, Go не нужен
```

Дополнительно:

```sh
make test           # тесты, через Docker
make release-docker # 5 бинарников в dist/ для других ОС + SHA256SUMS, через Docker
make docker-image   # образ hello-guest:$(VERSION), тег из git describe
```

Если Go установлен, для разработки можно без сборки:

```sh
go run ./cmd/hello-guest --addr :8080
```

## Запуск

Два способа: из бинарника на машине или в Docker-контейнере.

### Из бинарника

Соберите файл любым способом из раздела «Сборка», затем:

```sh
./dist/hello-guest                # порт 80, при нехватке прав — 8080
./dist/hello-guest --addr :8080   # явный порт
./dist/hello-guest --data ./data  # каталог данных (по умолчанию ./data)
./dist/hello-guest --name hello   # mDNS-имя: http://hello.local
./dist/hello-guest -d             # показать PIN и адреса, уйти в фон (лог: data/hello-guest.log)
./dist/hello-guest --version
```

При старте в консоль печатается PIN и адреса:

```
  PIN: 123456

hello-guest запущен
  http://hello-guest.local      # из той же Wi-Fi (mDNS)
  http://192.168.1.42           # по IP компьютера, запасной вариант
```

Если приложение запустилось на 8080 (нет прав на 80), к обоим адресам в консоли добавляется `:8080`. С телефона в той же сети откройте адрес, введите PIN; дальше всё делается касаниями.

### В Docker-контейнере

Собрать образ и запустить контейнер (данные — в папке `data/` репозитория, она в .gitignore):

```sh
make docker-image
mkdir -p data
docker run -d --name hg -p 8080:80 -v ./data:/app/data --memory=128m --cpus=0.5 hello-guest:$(git describe --tags --always)
docker logs hg   # PIN при первом запуске
```

## Первые шаги на мероприятии

1. Открыть приложение и ввести PIN.
2. Открыть вкладку **Источники** (на пустом экране есть кнопка «Загрузить выгрузку»).
3. Указать имя мероприятия и выбрать CSV-файл выгрузки Timepad.
4. Нажать **Импортировать файл**.
   - Вариант вместо файла: указать ID события Timepad и нажать **Подтянуть из Timepad**. Токен не нужен, если на сервере задана переменная окружения `TIMEPAD_TOKEN`.

После импорта откроется мероприятие с полным списком гостей. Искать гостя можно по имени, email, телефону или номеру билета; касание по строке отмечает приход, повторное — снятие. Вкладка «+ Гость» добавляет пришедшего без записи, вкладка «Статистика» показывает скорость, средний интервал и разбивку по типам билетов.

Повторный импорт того же файла безопасен: уже отмеченные гости не сбрасываются, дубли по email схлопываются.

## Формат CSV

Ожидается выгрузка Timepad с такими колонками:

```
Номер заказа,Дата создания,Статус,Email,Тип билета,Номер билета,EAN,Имя,Фамилия,Телефон,Промокод,Сумма
```

Колонки распознаются без учёта регистра, по списку синонимов: «номер билета», «билет» и «номер» — одно и то же поле. Порядок колонок не важен, лишние игнорируются.

## API (кратко)

Все эндпоинты, кроме `/`, требуют заголовок `X-Pin`.

| Метод | Путь | Назначение |
|---|---|---|
| POST | `/api/pin` | проверка PIN |
| GET | `/api/events` | список мероприятий со счётчиками |
| GET | `/api/state?event=` | все гости мероприятия |
| POST | `/api/checkin` | `{"event","guest_id","device","via"}` — отмечает гостя пришедшим; повторный вызов возвращает `already:true` и ничего не меняет |
| POST | `/api/undo` | снять отметку |
| POST | `/api/guest` | `{"event","name","phone","email","ticket_type"}` — добавляет гостя, которого нет в выгрузке (пришёл без записи) |
| POST | `/api/import?event=` | тело — CSV-файл |
| POST | `/api/refresh` | `{"event","timepad_id","token"}` — загрузка данных из Timepad API |
| GET | `/api/stats?event=` | счётчики |
