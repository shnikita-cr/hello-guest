# Обзор

Hello Guest — система для стойки регистрации гостей: список гостей из Timepad на планшете или телефоне, отметка прихода касанием или сканером QR/штрих-кода. Работает без интернета: локальный сервер на компьютере, все устройства синхронизируются между собой.

Руководство — для администратора стойки регистрации; начните со страницы «Запуск».

## Страницы инструкции

- **[Запуск](startup.md)** — как установить программу на компьютер, открыть её в браузере, обновить версию.
- **[Главная страница](home.md)** — вход, список гостей, команды, сканер, добавление гостей, статистика, источники.
- **[Экран статуса](status.md)** — состояние сервера, подключённые устройства, резервные копии, перезапуск и остановка.
- **[Панель администратора](admin.md)** — отчёт регистраций и журнал действий.
