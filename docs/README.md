# Обзор

Hello Guest — система для стойки регистрации гостей: список гостей из Timepad на планшете, отметка прихода касанием или сканером QR-кода. Работает без интернета: локальный сервер на компьютере, все устройства синхронизируются между собой.

Руководство рассчитано на администратора стойки регистрации: после прочтения страницы «Запуск» вы установите программу и откроете её в браузере, после страницы «Главная страница» — разберётесь в ежедневной работе со списком гостей.

## Это сервер

Программа, которая запускается на компьютере, — это сервер. В её окне печатается только служебная информация; работать вы будете в браузере на планшете или телефоне. Окно сервера не закрывайте: вместе с ним остановится сервис. Окно можно свернуть в таскбар; управлять и останавливать сервер удобнее всего с [экрана статуса](status.md).

## Страницы инструкции

- **[Запуск](startup.md)** — как установить программу на компьютер, открыть её в браузере, обновить версию.
