# Обзор

Hello Guest — система регистрации гостей на мероприятии. Список загружается из выгрузок Timepad (сервис, через который продаются билеты), отметка о прибытии ставится касанием записи или сканированием QR-кода билета.

Приложение работает без интернета: программа-сервер запускается на компьютере, а браузеры подключаются к нему в локальной сети.

Руководство предназначено для администратора стойки регистрации. Начните со страницы «Запуск».

## Разделы руководства

- **[Запуск](startup.md)** — загрузка и установка, первый запуск, подключение браузера, обновление версии, папка данных и резервные копии.
- **[Главная страница](home.md)** — вход, выбор мероприятия, импорт гостей, регистрация прибытия, команды и статистика.
- **[Экран статуса](status.md)** — состояние сервера, подключённые устройства, резервные копии, перезапуск и остановка.
- **[Панель администратора](admin.md)** — отчёт регистраций и журнал действий.
