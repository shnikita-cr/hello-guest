# Обзор

**Hello Guest** — система регистрации гостей на мероприятиях. Приложение позволяет загрузить список участников из Timepad, отмечать прибытие вручную или сканированием QR-кода либо штрихкода билета и формировать отчёты.

Сервер работает на компьютере, а сотрудники стойки регистрации используют браузер на планшете или смартфоне в той же локальной сети. Для регистрации по загруженному списку подключение к интернету не требуется. Загрузка данных непосредственно из Timepad требует доступа к сервису.

Руководство предназначено для сотрудников, отвечающих за запуск системы и регистрацию гостей. Перед началом работы изучите раздел «Запуск».

## Разделы руководства

- **[Запуск](startup.md)** — установка, подключение устройств, обновление программы и восстановление данных.
- **[Главная страница](home.md)** — выбор мероприятия, импорт участников, регистрация прибытия и работа с командами.
- **[Экран статуса](status.md)** — сведения о работе сервера, подключениях и резервных копиях, управление сервером.
- **[Панель администратора](admin.md)** — выгрузка отчётов и просмотр журнала действий.
