# Панель администратора

Панель администратора доступна в браузере устройства, подключённого к той же локальной сети, что и сервер.

## Подключение

К адресу приложения добавьте путь `/admin`. Например, если приложение открывается по адресу `https://192.168.1.42:8443`, адрес панели администратора — `https://192.168.1.42:8443/admin`.

При открытии панели введите тот же PIN-код, который используется для входа в приложение. Он отображается в окне сервера.

## Отчёт о регистрации

Для получения списка гостей с отметками о прибытии:

1. Выберите мероприятие.
2. Укажите формат CSV или XLSX.
3. Нажмите «Скачать отчёт».

Отчёт будет загружен браузером и сохранён на сервере в каталоге `data/reports`. Сведения о сохранении отображаются под кнопкой.

## Журнал действий

Журнал обновляется автоматически. Для каждого события отображаются время, мероприятие и тип действия:

- **✓** — регистрация прибытия из списка или по QR-коду; при наличии указывается название устройства;
- **↺** — повторное сканирование билета уже отмеченного гостя;
- **−** — снятие отметки о прибытии;
- **+** — добавление гостя вручную;
- **✗** — сканирование неизвестного билета.

Название устройства не всегда позволяет определить конкретного сотрудника, выполнившего действие.
