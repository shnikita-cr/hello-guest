# Панель администратора

Панель открывается в браузере на любом устройстве в той же сети, где работает сервер.

## Где взять адрес

Сервер печатает адреса в окне программы при запуске — строки «Адрес подключения в браузере», например `https://192.168.1.42:8443`. К адресу добавьте путь `/admin`: `https://192.168.1.42:8443/admin`. Если главная страница уже открыта, добавьте `/admin` к её адресу.

При открытии введите PIN — тот же, что на главной странице; он печатается в окне сервера.

## Отчёт регистраций

Отчёт — итоговый список по мероприятию с отметками прихода.

1. Выберите мероприятие.
2. Выберите формат: CSV или XLSX.
3. Нажмите «Скачать отчёт».

Браузер загрузит файл. На сервере он также сохраняется в папку `reports` внутри папки данных; об этом сообщает строка под кнопкой.

## Журнал действий

Журнал обновляется автоматически. В каждой строке — время, мероприятие и событие:

- **✓** — отмечен гость: по QR-коду или из списка, с указанием имени устройства, если оно было задано;
- **↺** — повторное сканирование уже отмеченного гостя;
- **−** — снята отметка прихода;
- **+** — гость добавлен вручную (пришёл без записи);
- **✗** — сканирование, по которому никто не найден.
