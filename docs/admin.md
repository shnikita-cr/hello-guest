# Админ

Страница администратора открывается в браузере на любом устройстве в той же сети, где работает сервер.

## Где взять адрес

Сервер печатает адреса в своём окне при запуске — строки «Адрес подключения». Нужен адрес компьютера с сервером, например `Адрес подключения: http://192.168.1.42`. К адресу добавьте путь `/admin`: `http://192.168.1.42/admin`.

Если вы уже открыли главную страницу `https://192.168.1.42:8443`, то админ находится по тому же адресу с путём `/admin`: `https://192.168.1.42:8443/admin`. Браузер предупредит о незнакомом сертификате — разрешите переход.

При открытии введите PIN — тот же, что на главной странице; он печатается в окне сервера.

## Отчёт регистраций

Отчёт — итоговый список по мероприятию, с отметками прихода.

1. Выберите мероприятие.
2. Выберите формат: CSV или XLSX.
3. Нажмите «Скачать отчёт».

Файл скачается в браузер. На сервере он также сохраняется в папку `reports` внутри папки данных; об этом сообщает строка под кнопкой.

## Журнал действий

Журнал обновляется сам каждые пять секунд. По каждой строке видно время, мероприятие и событие:

- **✓** — отмечен гость: по QR-коду или из списка, с указанием имени устройства, если оно было задано;
- **↺** — повторное сканирование уже отмеченного гостя;
- **−** — снята отметка прихода;
- **+** — гость добавлен вручную (пришёл без записи);
- **✗** — сканирование, по которому никто не найден.

Журнал показывает, кто и когда отметил гостя.
