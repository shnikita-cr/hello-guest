# Запуск

## Как работает программа

Когда вы открываете файл Hello Guest, на компьютере запускается сервер: в окне программы печатаются служебные строки — адреса, PIN и сообщения о работе.

Работаете вы в браузере: откройте его на планшете или телефоне в той же сети, что и компьютер.

Окно сервера не закрывайте — вместе с ним остановится сервис. Свернуть его можно клавишей Enter: окно уйдёт в фон и продолжит работать. Перезапустить или остановить программу можно кнопками на [экране статуса](status.md).

## Что скачать

Файлы лежат на странице релизов GitHub (раздел **Releases**). Для вашей системы:

| Система | Файл |
|---|---|

Вместе с программами в релизе лежит этот же документ в виде PDF-инструкции — файл `hello-guest-manual.pdf`.

## Первый запуск

1. Создайте папку, например `HelloGuest` на рабочем столе, и поместите в неё скачанный файл.
2. Запустите файл двойным щелчком. Откроется окно программы — это окно сервера, закрывать его не нужно.
3. В окне появятся строки. Важны следующие:

   - `PIN: ...` — код, которым вы войдёте в приложение;
   - `Адрес подключения в браузере: ...` — адрес сервера для браузера;
   - `Принудительное обновление версии в браузере после перезапуска сервера: ...` — откройте ссылку, если после перезапуска браузер показывает старую версию приложения: кэш очистится и откроется свежая страница.

   Таких строк может быть несколько: сервер печатает адрес для каждой сети компьютера. Какая из сетей ваша — сервер не знает. Подходит тот адрес, по которому ваше устройство видит компьютер; обычно это адрес вида `192.168.1.42` из вашей сети Wi-Fi. Если адрес не открывается — попробуйте следующий из списка.

   Перед адресами окно сообщает о работе сервера: `Сервер Hello Guest запущен успешно`, `Сертификат: ...`, `Резервные копии каждые 5 минут: ...`. Строка `TLS: ...` или `TLS недоступен: ...` означает неполадку — HTTPS-адреса не откроются: удалите файлы `tls.crt` и `tls.key` из папки `data` и запустите программу заново, сертификат создастся снова. Если строк «Адрес подключения в браузере» нет вовсе, компьютер не подключён к сети — подключите его к Wi-Fi и перезапустите программу.

4. Откройте браузер на планшете или смартфоне и наберите один из адресов «Адрес подключения в браузере», напечатанных в окне сервера, например `https://192.168.1.42:8443`. Браузер предупредит о незнакомом сертификате — разрешите переход. Сертификат самоподписанный, программа создаёт его сама.
5. Введите PIN — можно работать.

## Если страница не обновляется

Откройте в браузере страницу принудительного обновления (адрес печатает сервер — строка «Принудительное обновление версии в браузере после перезапуска сервера»; если окно сервера закрыто — наберите адрес компьютера с путём `/reset`). Страница очистит кэш браузера и откроет свежую версию приложения; PIN введите заново.

## Обновление версии

1. Скачайте новый файл из релизов.
2. Остановите сервер: на [экране статуса](status.md) нажмите «Остановить» — или закройте окно сервера.
3. Удалите старый файл программы и положите на его место новый.
4. Запустите новый файл.

Все гости, отметки и PIN сохраняются: данные лежат в папке `data` рядом с программой и от файла программы не зависят.

## Папка данных

Рядом с программой создаётся папка `data`. В ней:

- `hello-guest.ndjson` — журнал: все гости, отметки и изменения;
- `config.json` — файл с PIN, он же печатается в окне сервера при первом запуске;
- `tls.crt` и `tls.key` — сертификат для HTTPS, программа создаёт его автоматически;
- `hello-guest.log` — журнал работы, если программа запущена с флагом `-d`;
- `imports/` — сохранённые копии загруженных выгрузок;
- `reports/` — сохранённые отчёты.

PIN создаётся один раз при первом запуске — изменить его из программы нельзя.

Папку `data` не перемещайте и не переименовывайте — при обновлении версии её оставляют на месте. Резервные копии папки `data` программа каждые пять минут складывает в соседнюю папку `copy-data`. Если папку `data` удалили, программа при следующем запуске создаст новую с пустым списком и новым PIN — старые данные верните из [резервной копии](#восстановление-из-резервной-копии).

## Восстановление из резервной копии

Копии лежат в папке `copy-data` рядом с папкой `data`; её путь печатается в окне сервера — строка «Резервные копии каждые 5 минут». Если данные потерялись или повреждены:

1. Остановите программу.
2. Возьмите последний файл вида `hello-guest-20261020-143000.zip`.
3. Распакуйте его содержимое в папку `data` — поверх существующих файлов.
4. Запустите программу: PIN, гости и отметки вернутся из копии.

Копия создаётся каждые пять минут, поэтому восстанавливается состояние не позднее чем за пять минут до её создания; более поздние отметки потеряются. Ручная копия (кнопка на [экране статуса](status.md)) фиксирует состояние на момент нажатия.
