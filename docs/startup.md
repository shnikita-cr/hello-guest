# Запуск

## Как работает программа

Файл программы запускает локальный сервер. Служебная информация — адреса подключения, PIN, сообщения о работе — отображается в окне программы.

С приложением работают в браузере — на планшете или телефоне в той же сети, что и компьютер.

Окно программы не закрывайте: вместе с ним остановится сервер. Свернуть окно в фоновый режим можно клавишей Enter в окне программы — сервер продолжит работать. Перезапуск и остановка выполняются кнопками на [экране статуса](status.md).

## Загрузка и установка

Файлы лежат на [странице релизов GitHub](https://github.com/shnikita-cr/hello-guest/releases) в разделе **Releases**. Каждый файл — программа-сервер Hello Guest для своей операционной системы:

| Система | Файл |
|---|---|
| Windows | `hello-guest-windows-amd64.exe` |
| macOS (чип Apple) | `hello-guest-darwin-arm64` |
| Linux (x86-64) | `hello-guest-linux-amd64` |
| Linux (ARM) | `hello-guest-linux-arm64` |

В том же релизе лежит руководство в PDF — файл `hello-guest-manual.pdf`.

## Первый запуск

1. Создайте папку для программы, например `HelloGuest` на рабочем столе, и поместите в неё скачанный файл.
2. Запустите файл двойным щелчком. Открывается окно сервера; сворачивайте его в фон, но не закрывайте.
3. Дождитесь строк в окне программы:

   ```text
   PIN: 482913
   Сервер Hello Guest запущен успешно
   Сертификат: data/tls.crt
   Резервные копии каждые 5 минут: ../copy-data
   Нажмите Enter в этом окне, чтобы свернуть его в фон

   Адрес подключения в браузере: https://192.168.1.42:8443
   Программа отображает адреса всех сетевых интерфейсов компьютера
   Используйте адрес, доступный с планшета или смартфона в локальной сети
   Принудительное обновление версии в браузере после перезапуска сервера: https://192.168.1.42:8443/reset
   ```

   Перед этими строками окно печатает логотип программы. Содержимое зависит от компьютера: адреса выводятся для каждого сетевого интерфейса, путей и сертификатов — в зависимости от места запуска.

   - `PIN` — код для входа в приложение. Он сохраняется в `data/config.json` и не меняется, пока не изменится сам этот файл.
   - `Адрес подключения в браузере` — адрес приложения. Откройте его в браузере планшета или смартфона; если адрес не открывается, попробуйте следующий из списка. Выбирайте адрес из локальной сети, вида `192.168.1.42`.
   - `Принудительное обновление версии в браузере после перезапуска сервера` — ссылка на страницу сброса, раздел «Если страница не обновляется».

   Если адресов нет, компьютер не подключён к сети: подключите его к Wi-Fi и перезапустите программу.

   Строка `TLS: ...` или `TLS недоступен: ...` означает неполадку: HTTPS-адреса не откроются. Удалите файлы `tls.crt` и `tls.key` из папки `data` и запустите программу заново — сертификат создастся снова.

4. Откройте адрес `https://192.168.1.42:8443` в браузере устройства. Браузер предупредит о незнакомом сертификате — разрешите переход: сертификат самоподписанный, программа создаёт его самостоятельно.
5. Введите PIN. После авторизации откроется главная страница приложения, раздел «Гости».

## Если страница не обновляется

После перезапуска сервера браузер может держать старую версию приложения. Откройте в браузере ссылку сбрасывания из окна программы (строка «Принудительное обновление версии в браузере после перезапуска сервера»), например `https://192.168.1.42:8443/reset`, и нажмите «Сбросить сейчас». Страница очистит кэш браузера и откроет свежую версию приложения; PIN введите заново.

Если в приложении отображается «нет связи» с числом отметок в очереди, дождитесь отправки отметок: сброс удаляет локальные данные приложения, включая очередь неотправленных отметок.

## Обновление версии

1. Скачайте [новую версию из релизов](https://github.com/shnikita-cr/hello-guest/releases).
2. Остановите сервер: на [экране статуса](status.md) нажмите «Остановить» или закройте окно программы.
3. Удалите старый файл программы и поместите на его место новый.
4. Запустите новый файл.

Гости, отметки и PIN сохраняются: данные лежат в папке `data` и от файла программы не зависят.

## Папка данных

Рядом с программой создаётся папка `data`:

- `config.json` — настройки сервера и PIN; создаётся при первом запуске, изменить PIN из программы нельзя.
- `state.json` — гости, отметки и события, текущее состояние.
- `tls.crt`, `tls.key` — создаваемый самой программой сертификат.
- `hello-guest.log` — журнал работы, если программа работает в фоновом режиме.
- `imports/`, `reports/` — сохранённые выгрузки Timepad и отчёты регистраций.

Папку не перемещайте и не переименовывайте. Каждые пять минут программа складывает резервные копии папки в `copy-data` — на уровень выше папки программы; точный путь печатается в окне программы в строке «Резервные копии каждые 5 минут».

Если папка `data` удалена, программа при следующем запуске создаёт её заново с пустым списком и новым PIN. Старые данные верните из резервной копии.

## Восстановление из резервной копии

Копии — zip-архивы папки данных — создаются каждые пять минут в `copy-data`; хранятся последние двадцать. На [экране статуса](status.md) можно создать дополнительную копию вручную.

Восстановление возвращает данные на момент создания выбранной копии. Отметки и изменения, сделанные после этого момента, в копию не попадают.

1. Остановите программу.
2. Переименуйте текущую папку данных — например, `data` в `data-old`: существующие файлы сохранятся на случай, если копия не подойдёт.
3. Создайте пустую папку `data` рядом с программой и распакуйте в неё содержимое последнего архива из `copy-data` (имя вида `hello-guest-20261020-143000.zip`).
4. Запустите программу: PIN, гости и отметки вернутся из копии.
