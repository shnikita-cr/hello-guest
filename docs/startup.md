# Запуск

## Это сервер

Hello Guest — сервер для компьютера. Программа работает на компьютере как сервер, а интерфейс — это веб-страницы, которые открываются в браузере на планшете или телефоне. Окно сервера не закрывайте: вместе с ним сервис остановится. Окно можно свернуть в таскбар; управлять и останавливать сервер удобнее всего с [экрана статуса](status.md).

## Что скачать

Файлы лежат на странице релизов GitHub (раздел **Releases**). Для вашей системы:

| Система | Файл |
|---|---|
| Windows | `hello-guest-windows-amd64.exe` |
| Mac (Apple Silicon) | `hello-guest-darwin-arm64` |
| Linux | `hello-guest-linux-amd64` |

Вместе с программами в релизе лежит этот же документ в виде PDF-инструкции — файл `hello-guest-manual.pdf`.

## Первый запуск

1. Создайте папку, например `HelloGuest` на рабочем столе, и поместите в неё скачанный файл.
2. Запустите файл двойным щелчком. Откроется окно программы — это окно сервера, закрывать его не нужно.
3. В окне появятся строки. Важны следующие:

   - `PIN: ...` — код, которым вы войдёте в приложение;
   - `Адрес подключения: ...` — адрес сервера для браузера;
   - `Сброс браузера: .../reset` — страница, которая очищает кэш браузера, если страница приложения ведёт себя не так, как нужно.

   Таких строк может быть несколько: сервер печатает адрес для каждой сети компьютера. Какая из сетей ваша — сервер не знает. Подходит тот адрес, по которому планшет видит компьютер; обычно это адрес вида `192.168.1.42` из вашей сети Wi-Fi. Если адрес не открывается — попробуйте следующий из списка.

4. Откройте браузер на планшете и наберите один из адресов «Адрес подключения», напечатанных в окне сервера, например `https://192.168.1.42:8443`. Браузер предупредит о незнакомом сертификате — разрешите переход. Сертификат самоподписанный, программа создаёт его сама.
5. Введите PIN — можно работать.

## Если браузер завис

Откройте на планшете страницу `Сброс браузера` (адрес печатает сервер при запуске; если окно сервера закрыто — наберите адрес компьютера с путём `/reset`). Страница очистит кэш браузера и откроет свежую версию приложения; PIN введите заново.

## Обновление версии

1. Скачайте новый файл из релизов.
2. Остановите сервер: на [экране статуса](status.md) нажмите «Остановить» — или закройте окно сервера.
3. Удалите старый файл программы и положите на его место новый.
4. Запустите новый файл.

Все гости, отметки и PIN сохраняются: данные лежат в папке `data` рядом с программой и от файла программы не зависят.

## Папка данных

Рядом с программой создаётся папка `data`. В ней:

- `hello-guest.ndjson` — журнал: все гости, отметки и изменения;
- `config.json` — файл с PIN (он же печатается в окне сервера);
- `tls.crt` и `tls.key` — сертификат для HTTPS, программа создаёт его автоматически;
- `hello-guest.log` — журнал работы, если программа запущена с флагом `-d`;
- `imports/` — сохранённые копии загруженных выгрузок;
- `reports/` — сохранённые отчёты.

Папку `data` переносить и переименовывать не нужно; при обновлении версии её не трогают. Резервные копии папки `data` программа каждые пять минут складывает в соседнюю папку `copy-data`.
