# Экран статуса

Экран статуса — веб-страница состояния сервера. Откройте её на том же компьютере, где работает сервер: `https://127.0.0.1:8443/status`. Страница доступна только с этого компьютера — по сети извне она не открывается.

## Что показывает

- **Сервис** — работает сервер или нет, версия программы и время работы.
- **Клиентов онлайн** — сколько устройств держат открытую страницу приложения (за последние десять секунд) и список последних подключений и выходов.
- **Доступен по** — HTTPS-адреса для планшетов и телефонов.
- **Резервная копия** — время последней автоматической и последней ручной копии.

Сердце в шапке: красное — сервер отвечает, синее — связи нет.

## Кнопки

- **«Перезапустить»** перезапускает сервер. После перезапуска страница автоматически восстановит соединение и обновится.
- **«Остановить»** полностью останавливает сервер. После остановки запускайте сервер снова вручную: запустите файл программы на компьютере.
- **«Создать дополнительный ручной бэкап»** создаёт резервную копию папки с данными вручную. Если данные не менялись с прошлого раза, копия пропускается.

Автоматические резервные копии создаются сами каждые пять минут; хранятся последние двадцать. Управлять ими на этой странице не нужно.
