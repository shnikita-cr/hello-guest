# Экран статуса

Экран статуса доступен на компьютере, где запущен сервер, по адресу `https://127.0.0.1:8443/status`. Подключение к этой странице с других устройств локальной сети ограничено.

## Сведения о сервере

- **Сервис** — состояние, версия программы и время непрерывной работы.
- **Клиентов онлайн** — количество устройств с открытым приложением за последние десять секунд, история подключений и отключений.
- **Доступен по** — HTTPS-адреса для подключения устройств регистрации.
- **Резервная копия** — время создания последних автоматической и ручной копий.

Значок сердца показывает соединение с сервером: красный — соединение установлено, синий — соединение отсутствует.

## Управление

- **«Перезапустить»** — перезапускает сервер; после восстановления соединения страница обновляется.
- **«Остановить»** — завершает работу сервера. Для последующего запуска откройте исполняемый файл на компьютере.
- **«Создать дополнительный ручной бэкап»** — создаёт резервную копию данных. Если содержимое данных не изменилось с момента предыдущего копирования, новая копия может не создаваться.

Автоматическое резервное копирование выполняется каждые пять минут, хранятся последние двадцать копий. Порядок восстановления описан в разделе [«Восстановление из резервной копии»](startup.md#восстановление-из-резервной-копии).
