# Главная страница

Откройте приложение в браузере устройства регистрации по одному из адресов, указанных в окне сервера.

## Вход

Введите PIN-код и нажмите «Войти». Для всех подключаемых устройств используется один PIN-код, отображаемый в окне сервера. Приложение сохраняет сведения для повторного входа на устройстве.

## Выбор мероприятия

После входа отображается список мероприятий. Выберите мероприятие, чтобы открыть его список гостей. Если список мероприятий пуст, нажмите «Загрузить выгрузку» и перейдите к разделу «Источники».

## Источники

Список гостей загружается на вкладке «Источники». Открыть её можно через нижнюю панель или кнопку «Загрузить выгрузку».

- **Импорт файла.** Укажите мероприятие, выберите выгрузку Timepad в формате CSV или XLSX и нажмите «Импортировать файл».
- **Загрузка из Timepad.** Укажите мероприятие и идентификатор события в Timepad, затем нажмите «Подтянуть из Timepad». Для обращения к сервису необходим доступ к интернету и соответствующая настройка доступа к API.

При повторном импорте того же файла программа сохраняет существующие отметки о прибытии и данные команд. Перед работой с изменёнными выгрузками проверьте результаты сопоставления записей.

## Список гостей

В верхней части страницы расположены:

- счётчики «Билеты: пришло X / Y» и «Гости: пришло X / Y»; второй счётчик также учитывает гостей, добавленных вручную;
- переключатель представлений «Гости» и «Команды»;
- поиск по имени, адресу электронной почты, телефону и номеру билета;
- кнопка «Сканировать QR/штрих-код».

Нажмите на запись гостя, чтобы отметить его прибытие. Для снятия отметки нажмите на запись повторно и подтвердите действие. Зелёная рамка обозначает уже отмеченного гостя.

Значок сердца в верхней части страницы показывает состояние соединения: красный — сервер доступен, синий — соединение отсутствует.

При потере связи действия сохраняются в локальной очереди и отправляются при восстановлении соединения. Сообщение «нет связи, N в очереди» показывает количество ожидающих отправки действий. Не очищайте данные браузера, пока очередь не опустеет.

## Сканирование QR-кода или штрихкода

1. Нажмите «Сканировать QR/штрих-код».
2. Наведите камеру на код билета.
3. Дождитесь регистрации прибытия гостя. После обработки кода сканер остаётся активным для следующего билета.

Считывания, для которых не найден соответствующий билет, учитываются в статистике как нераспознанные. Название показателя в интерфейсе может отличаться.

## Добавление гостя

Нажмите «+ Гость» в нижней панели. Укажите имя гостя; телефон, адрес электронной почты и тип билета заполняются при необходимости. Кнопка «Сохранить и отметить» создаёт запись с отметкой о прибытии, а «Сохранить без отметки» — запись без отметки.

## Представление «Команды»

В этом представлении отображаются командные билеты. Нажмите на карточку команды, чтобы раскрыть список участников.

- Для регистрации отдельного участника нажмите на его запись. Отметки участников ведутся поимённо.
- Кнопка «+ Гость» внутри команды добавляет нового участника.
- Кнопка «+ Участник» позволяет включить в команду гостя, который уже присутствует в списке. Если он состоит в другой команде, приложение запрашивает подтверждение переноса.
- Кнопка «+ Команда» в нижней панели создаёт команду. Укажите название и участников через запятую; первый участник в списке будет капитаном.

Карточка команды отображается как прибывшая, если отмечен хотя бы один её участник. Если отметки отсутствуют у всех участников, карточка отображается без отметки. Показатель «Полных команд: пришло X / Y» учитывает команды, в которых отмечены все участники.

## Статистика

Вкладка «Статистика» содержит общее количество гостей и прибывших, скорость регистрации за последние десять минут, средний интервал между регистрациями, распределение по способам отметки и типам билетов. В статистике также учитываются нераспознанные сканирования, обозначенные в интерфейсе как «ложные QR».
